# Documentation index

This directory is the durable project state for humans and agents.

| File | Purpose |
| --- | --- |
| `GOAL.md` | Problem, intended outcome, non-goals, success conditions. |
| `REQUIREMENTS.md` | Testable functional and non-functional requirements. |
| `PLAN.md` | Current execution phases, milestones, and exit criteria. |
| `DESIGN.md` | Current architecture, interfaces, important invariants, and trade-offs. |
| `TESTING.md` | Verification strategy, commands, environments, and known gaps. |
| `DECISIONS.md` | Durable decisions and links to ADRs when needed. |
| `RISKS.md` | Known risks, uncertainties, mitigations, and owners/status. |
| `TRACEABILITY.md` | Links from goals/requirements/tickets to implementation and evidence. |
| `KNOWLEDGE.md` | Project-owned domain knowledge and evidence provenance. |
| `HANDOFF.md` | Current operational state for the next session/agent. |
| `../SECURITY.md` | Security trust boundaries, invariants, AI/agent controls, and known gaps. |
| `adr/` | Architecture/engineering decision records. |

Update only the document that owns the information. Avoid duplicating the same fact across many files.
