# Project knowledge base

Capture durable domain knowledge that the project should own rather than repeatedly re-derive from chats.

## Knowledge entries

For important claims record:

- **Claim:** [what is believed to be true]
- **Scope/version:** [where/when it applies]
- **Evidence/source:** [local experiment, code inspection, official docs, etc.]
- **Confidence:** [high/medium/low and why]
- **Implication:** [what decisions or implementation depend on it]

Put stable source snapshots, local runbooks, schemas, and other supporting material under `reference/`. Do not promote an agent guess into project knowledge without evidence.
